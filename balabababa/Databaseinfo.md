# balabababa 综合科研数据库自动检索系统

## 概述

本系统提供自动化的多数据库检索能力。AI根据用户需求，**通过理解用户意图**选择合适的数据库，然后加载对应的skill文件执行具体查询。

---

## 数据库索引表

| 数据库 | 目录 | 用途 | 适用场景 |
|--------|------|------|----------|
| **Plant SRA API** 🚀 | `NCBI/PlantSRA_API.md` | **植物**SRA数据快速检索（API，<0.3s） | 用户想获取**植物物种**的原始测序数据(SRR)，优先使用 |
| NCBI SRA | `NCBI/NCBIdb.md` | 全物种重测序/WGS数据检索下载（Entrez） | 非植物物种，或 API 不可用时的 fallback |
| RiceGeneFunction | `RiceGeneFunction/ricegenefunction.md` | 水稻基因功能注释查询 | 用户想知道某个水稻基因的功能 |
| ArabidopsisGeneFunction | `ArabidopsisGeneFunction/arabidopsisgenefunction.md` | 拟南芥基因功能注释查询 | 用户想查询拟南芥基因功能或搜索特定功能相关基因 |

> **⚠️ 重要变更**：植物 SRA 查询现在有**双路径**——优先走 PlantSRA API（阿里云，686万条索引，<0.3s），API 不可达或结果不足时自动 fallback 到 NCBI Entrez（`NCBIdb.md`）。

## AI意图判断逻辑

### 核心原则

**不是简单的关键词匹配，而是理解用户真正想做什么。**

### 意图判断流程

```
┌─────────────────────────────────────────────────────────────────┐
│                        用户请求分析                              │
├─────────────────────────────────────────────────────────────────┤
│                                                                 │
│  Step 1: 理解用户想获取什么类型的数据？                            │
│                                                                 │
│  ┌─────────────────────────────────────────────────────────┐    │
│  │ 原始测序数据？  →  用户需要SRR/SRA原始reads              │    │
│  │     ↓                                                       │    │
│  │ 是否与物种/基因组相关？                                      │    │
│  │     ↓                                                       │    │
│  │ 是下载/检索/搜索数据吗？                                     │    │
│  │     ↓                                                       │    │
│  │ 是植物物种？                                                │    │
│  │     ├── YES → 🚀 PlantSRA API (PlantSRA_API.md)           │    │
│  │     │          API不可达/结果不足？ → NCBI SRA (fallback)   │    │
│  │     └── NO  → 选择: NCBI SRA (NCBIdb.md)                  │    │
│  └─────────────────────────────────────────────────────────┘    │
│                                                                 │
│  ┌─────────────────────────────────────────────────────────┐    │
│  │ 基因功能信息？  →  用户想知道某基因的功能/注释              │    │
│  │     ↓                                                       │    │
│  │ 是否是水稻基因(Os01g...格式)？                             │    │
│  │     ↓                                                       │    │
│  │  → 选择: RiceGeneFunction                                  │    │
│  └─────────────────────────────────────────────────────────┘    │
│                                                                 │
└─────────────────────────────────────────────────────────────────┘
```

## 使用方法

### AI执行流程

```
1. 读取 balabababa/Databaseinfo.md 获取数据库索引
2. 理解用户请求，判断用户意图（而非仅匹配关键词）
3. 根据意图选择目标数据库：
   - 植物 SRA 检索？ → 🚀 PlantSRA API (先检查 API 健康)
   - 非植物 SRA？ → NCBI SRA (Entrez)
   - 基因功能？ → RiceGeneFunction / ArabidopsisGeneFunction
4. 加载对应的 .md skill文件
5. 按照skill文件的流程执行查询
6. 返回结果给用户
```

### 意图判断要点

AI在判断时应考虑以下因素：

1. **数据类型**：用户想要原始测序数据，还是基因功能信息？
2. **物种范围**：是植物物种吗？→ 优先 API 路径；非植物 → Entrez 路径
3. **上下文**：用户的关注点是"数据获取"还是"功能理解"？
4. **基因号格式**：是否提供了Os格式或LOC_Os格式的基因号？
5. **动词意图**：用户使用了"检索/下载/搜索"还是"查询/功能/注释"？

### 添加新数据库

如需扩展系统，按以下步骤添加：

```
1. 创建新目录: balabababa/{数据库简称}/
2. 编写 {数据库简称}db.md skill文件
3. 在 Databaseinfo.md 的索引表中添加条目
4. 在意图判断部分添加新的场景映射
```

## 数据库详情

### 🚀 PlantSRA API (新增)

**路径**: `NCBI/PlantSRA_API.md`

**功能**:
- 通过阿里云 API (`47.95.117.10:8080`) 快速检索植物 SRA 元数据
- FTS5 全文搜索引擎，686 万+ 植物 SRA 记录
- 响应速度 <0.3 秒（vs Entrez 的数秒～数分钟）
- 自动按 BioProject 去重聚合
- 支持逐条 SRR/DRR/ERR accession 列表

**适用场景**:
- 用户想快速了解某植物物种有哪些公开测序数据
- 用户需要 SRR 号进行下载分析
- 用户在检索/搜索/下载植物的 SRA/WGS/重测序数据

**与 NCBI SRA (Entrez) 的关系**:
- PlantSRA API = 快速路径（植物专用，优先使用）
- NCBI SRA = 完整路径（全物种 + API 不可用时的 fallback）
- 两个路径输出格式统一，用户无感知切换

**前置准备**: `curl`（系统自带，无需额外安装 🎉）

---

### NCBI SRA

**路径**: `NCBI/NCBIdb.md`

**功能**: 
- 检索NCBI Sequence Read Archive (SRA)的全基因组重测序数据
- 获取SRR/DRR/ERR accession列表
- 支持按物种、测序平台、数据量等条件筛选

**适用场景**:
- 用户想获取某物种的原始测序reads
- 用户需要SRR号进行下载分析
- 用户在检索/搜索/下载SRA/WGS/重测序数据

**前置准备**: agent-browser (npm install -g agent-browser)

---

### RiceGeneFunction

**路径**: `RiceGeneFunction/ricegenefunction.md`

**功能**:
- 查询RiceData水稻基因数据库
- 获取水稻基因的功能注释信息
- 支持Os格式和LOC_Os格式基因号

**适用场景**:
- 用户想知道某水稻基因的功能
- 用户提供了Os格式基因号询问功能
- 用户在查询/获取基因注释信息

**前置准备**: agent-browser (npm install -g agent-browser)

---

### ArabidopsisGeneFunction

**路径**: `ArabidopsisGeneFunction/arabidopsisgenefunction.md`

**功能**:
- 查询TAIR和Araport拟南芥基因数据库
- 获取拟南芥基因的功能注释信息
- 支持AT格式基因号 (AT1Gxxxxx)
- 支持功能关键词搜索
- **重要**: 中文关键词需翻译为英文再查询

**适用场景**:
- 用户想知道某拟南芥基因的功能
- 用户提供了AT格式基因号询问功能
- 用户搜索特定功能相关的拟南芥基因
- 用户使用中文查询（如"耐寒性基因"、"花发育基因"）

**中文→英文翻译示例**:
| 中文 | 英文 |
|------|------|
| 耐寒性 | cold tolerance / cold stress |
| 花发育 | flower development |
| 抗逆性 | stress response |
| 干旱胁迫 | drought tolerance |
| 盐胁迫 | salt stress |

**前置准备**: agent-browser (npm install -g agent-browser)
